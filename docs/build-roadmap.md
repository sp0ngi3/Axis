# Axis Build Roadmap

1. Foundation: repo, Docker, backend, frontend, launcher.
2. Core model: life areas, goals, milestones, activities, templates, metrics, reviews.
3. Planning: Today view, week calendar, quick activity logging.
4. Progress intelligence: milestone progress, balance dashboard, recovery-aware suggestions.
5. Review loop: weekly and monthly reviews.
6. Data safety: export/import backup.
7. Polish: filtering, pagination, richer calendar interactions, accessibility, tests.

The current implementation covers the foundation and the first useful MVP slice.
