# Axis Product Spec

Axis helps the user answer: given current goals, limited energy, and recent behavior, what should happen next?

The MVP includes life areas, goals, milestones, activities, a Today view, weekly calendar planning, metrics, reviews, balance analytics, SQLite storage, Docker setup, and backup export/import.

Axis prefers direction over perfection. Missed work is treated as planning feedback, not failure. Progress can be accumulated, maintained, or allowed to decay slowly depending on the goal.
